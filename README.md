# Personal Website: About Me

The first HTML + CSS project from the **Web Development 101** course at [Neps Academy](https://neps.academy). It is a single-page personal presentation, built with only HTML and CSS, that presents the following features:

## Features

- **Header:** the main title of the page.
- **Introduction:** a short paragraph about me, with a profile picture.
- **Hobbies:** an unordered list (`<ul>`) with my main interests, with some items highlighted.
- **Goals:** an ordered list (`<ol>`) with my goals for the course, career and personal life.
- **Footer:** links to my social/professional networks and a contact email.

